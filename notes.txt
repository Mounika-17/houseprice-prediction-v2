2. I will write my code in create_lightweight_data.py file and execute it to create my data/
3. Initially I have built the project same as my other ML projects using Flask
4. To deploy my project using Render FastAPI, what I did is I have updated my app.py code. Below are the list of the files that are added/updated:

| File                  | Action                                     |
| --------------------- | ------------------------------------------ |
| `app.py`              | ✨ Replace Flask code with new FastAPI code |
| `requirements.txt`    | Add FastAPI + uvicorn                      |
| `Procfile`            | Add Render start command                   |
| `runtime.txt`         | (Optional) Add Python version              |
| `predict_pipeline.py` | ✅ No change                                |
| `artifacts/`          | ✅ No change                                |

Difference in using the Flask and FastAPI:

| Item             | Current (Flask)                    | New (FastAPI)                                           |
| ---------------- | ---------------------------------- | ------------------------------------------------------- |
| Web framework    | Flask                              | FastAPI                                                 |
| Route syntax     | `@app.route()`                     | `@app.get()` / `@app.post()`                            |
| Form rendering   | HTML templates (`render_template`) | JSON-based API (you can still add HTML later if needed) |
| Request handling | `request.form.get()`               | Pydantic model (typed JSON request)                     |
| Output           | Rendered HTML                      | JSON response                                           |
| Deployment       | Not ideal for Render               | Fully supported on Render                               |
